# AidConnect

AidConnect is a CRM-based platform designed for NGOs to manage community interactions, complaints, and volunteer activities efficiently. It helps bridge the gap between NGOs and communities by providing a centralized system for communication, request management, and analytics.

## Features

- Community complaint / request submission
- NGO dashboard to track and manage issues
- Draggable kanban board
- Program and activity tracking
- Basic analytics to monitor NGO impact

## Tech Stack

**Frontend**
- React.js

**Backend**
- Node.js
- Express.js

**Database**
- MongoDB

## Installation

Clone the repository

```
git clone https://github.com/your-username/aidconnect.git
```

Install dependencies

```
npm install
```

Run the frontend

```
npm run dev
```
To run the Backend:
```
STEP 1: cd server
STEP 2: npm install
STEP 3: create .env file
STEP 4: Add the below details to the .env file
    PORT=5000
    MONGO_URI="yourmongouri"
    JWT_SECRET="yoursecretkey"
STEP 5: npm run dev
```
## Purpose

AidConnect aims to simplify NGO operations and improve transparency by providing a digital platform for managing community engagement and social initiatives.
